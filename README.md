### Project Description
RegretOS is a fake retro-futuristic supercomputer that overanalyzes tiny decisions you never needed help with. Type in a question, and it gives you a dramatic (and completely made-up) Regret Score, a random verdict, and a few other useless extras — all running on simple JavaScript with zero logins, zero backend, and zero actual intelligence.

### The Problem (that doesn't exist)
People make small decisions too quickly and too calmly. RegretOS fixes that by adding unnecessary drama, fake science, and mild existential panic — nobody asked, but here we are.

### The Solution (that nobody asked for)
RegretOS turns every trivial decision into a full-blown scientific event — a fake AI "consults," a Regret Score gets calculated out of thin air, and you walk away with an official (not legally binding) certificate proving you overthought something completely harmless.
